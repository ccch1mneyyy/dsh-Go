# 伙伴：养成和每天来看她

> 2026-11-09 起草，方向稿。owner 问：能不能靠伙伴系统提高粘性和日活，比如养成，或者每天上线互动。伙伴小屋现状见 [companion.md](companion.md)，角色数据和好感度的底座见 [roleplay.md](roleplay.md) §8。

## 0. 结论

- **每天来，靠的是「每天都有用」和「每天都有点不一样」。** DSH Go 的用户本来是来干活的，所以让她成为每天的入口：进门时她把你不在时发生的事讲给你听（别的对话跑完了、有事等你确认，以后再加上管家整理的消息），晚上写一页日记。小屋里每天潮水会带来一样小东西。
- **养成长在三条线上**：变熟（已有的亲近度，补上每一档解锁什么）、她的小屋（收集和装扮）、你们的回忆（日记、相册、纪念日）。没有货币、商店，也不收费。
- **不惩罚缺席。** 你几天没来，她不难过、不掉亲近度，也不发卖惨的通知；她过她自己的日子，你回来时讲给你听，没捡的东西还在。连续签到这类玩法做成选项，默认关，想要的人自己开（§4）。
- **先做不花 token 的**（每天的小东西、收藏册、纪念日、进门问候带上今天的事），再做花 token 的（日记、早安简报、主动开口）。花 token 的都写明一天大约用多少。
- **日活现在就能量。** App 已有匿名使用报告（按天、按安装去重、能算留存），加两个计数就能看伙伴和酒馆对留存的影响（§5）。

## 1. 已经有的

下面的设计都接在 companion.md §6 已有的东西上，不重做：

- 亲近度四档，每 6 小时最多 +0.01，不因缺席扣分；跨档时她蹦一下、说一句（§6.5）。
- 三件物件和活动（点心、泡泡球、软垫，§6.1），主动邀请（§6.4）。
- 作息（夜里犯困、清晨伸懒腰）；记忆（确认过的事接在人设后面）。
- 联动：别的对话跑完、出错、等批准时，她说一句，并给一个「去看看」胶囊。
- 桌面小组件：像素小鲸鱼、名字、亲近珠子、她在做什么、她最后说的话。
- 她的声音：系统 TTS、外接接口、克隆声音。

## 2. 每天

一天里有四个时刻，前两个不调模型。

### 2.1 潮水带来的东西

- 每天潮水往小屋里带一样东西：一枚贝壳、一个漂流瓶、一只路过的小生物（小鱼、海星、水母，待一会儿就游走），节日带节日的东西。凌晨 5 点换天，和作息一致；按日期和安装算种子，同一天打开几次都是同一样。
- 东西落在舞台下半部分的沙地上。你点一下，她游过去捡起来给你看，说一句（台词从素材包里取，不调模型），然后收进**收藏册**。
- **不过期。** 没来的那几天的东西都还在沙地上，最多摆 7 样，再多的直接收进收藏册，标「潮水留下的」。所以隔几天来一次也不会错过什么。
- 漂流瓶里是一张小纸条：台词库里的一句话；变熟以后，换成她前几天日记里的一句（§3.1）。

### 2.2 进门

- 每天第一次进小屋时，她的问候带上「今天的事」，作为旁白交给她（和现在的旁白一样，注明是资料、不是指令）：离开了多久、上次聊到的事（最近一条记忆或对话）、你不在时别的对话的结果（联动那条事件线攒下的）、今天是不是纪念日或节日、潮水带来了什么。
- 不多调一次模型：问候本来就要调，只是旁白多了几行。没有 Key 也没有主机时，用台词库。
- **她自己的日子。** 你不在时，规则层按离开的时长和时段给她排几件事（睡了一觉、把贝壳按颜色排好、跟小鱼玩了一下午），你回来时挑一件放进旁白，她讲给你听。离开换来的是故事，不是惩罚。

### 2.3 晚上的日记

- 晚上 9 点以后第一次离开小屋时，或者你点「今天的日记」，她写一页：三到五句，写今天你们聊了什么、你在小屋里做了什么、她注意到的事，用她的口吻。
- 日记存在这台手机上的**日记本**里，按日期翻。你可以在下面回一句（交换日记），她第二天进门时可能会提起。
- 写日记时顺带提议记忆：她觉得值得记的事走记忆的确认流程（roleplay.md §8 的记忆书），不直接写进去。
- 花费：每天调一次 `deepseek-flash`，输入约 2k token（人设、当天对话的摘录、当天的事），输出约 300。有 Key 走轻量模式那条路；没有 Key 时用当前主机上的伙伴会话。
- 菜单里三档：每天自动写 / 我点了才写 / 不写。默认每天自动写，第一页日记底下写一行它大约用多少 token、在哪里关。

### 2.4 早安简报

- 你设一个时间（比如 8:00），到点发一条通知，用她的口吻：「早呀，夜里那两个任务跑完了，有一个等你确认。」点开进小屋，她把细节讲一遍，带「去看看」胶囊。
- 内容：现在有别的对话的结果、等批准的事、主机上的定时任务；管家做好以后，加上它整理的 IM 和 GitHub 消息（router.md §4.4）。
- 通知的文案不调模型，按条数套台词；进小屋后那一段走正常的进门问候（§2.2）。
- 要新的原生定时：App 现在没有定时唤醒（没有 AlarmManager / WorkManager）。用不精确的闹钟窗口（±15 分钟），不用申请精确闹钟权限。后台连不上主机时，通知只用上次知道的情况，写「打开看看」。
- 通知走已有的 `dsh/notify`，加一个「她」的频道，能在系统设置里单独关。这个功能默认关，因为它要你选时间；在菜单里打开时请求通知权限。
- 「主动开口」（她用模型主动说话，companion.md §6.2 路线图里的那条）和简报共用这个频道和定时。

## 3. 养成

### 3.1 变熟

亲近度和四档的线不变（`companion_bond.dart`）。补两件事。

**哪些事算相处**：进小屋、聊天、点物件、捡潮水带来的东西、回日记、小屋开着陪你干活（别的对话在跑）。每 6 小时最多 +0.01 的上限照旧，所以刷不快，也不用刷。

**每一档解锁什么**（已经按档变化的那些行为照旧）：

| 档 | 线 | 新东西 |
|---|---|---|
| 刚认识 | 0 | 三件物件、收藏册、日记本 |
| 渐渐熟悉 | 0.03 | 相册（能在小屋里拍照）；漂流瓶里出现她写的纸条 |
| 熟起来了 | 0.10 | 装扮：把收来的东西摆进小屋（§3.2）；交换日记里她会回你写的话 |
| 很亲近 | 0.30 | 特别的早安和晚安；她会提起很久以前的事（从记忆和日记里翻）；纪念日的小惊喜 |

很亲近以后不再加档。长线靠回忆和收藏：认识第 100 天、第 365 天，收藏册集满一页。

### 3.2 她的小屋：收集和装扮

- **收藏册**：贝壳、漂流瓶的纸条、来过的小生物（图鉴）。节日和季节有专门的样子，但不是错过就没有：节日的东西第二年还会来，收藏册里那一格写着「明年春节」。
- **装扮**：熟起来以后，收来的东西能摆进小屋，放在沙地和礁石上几个固定的位置。这就是路线图里的「小房子第 2 期」（companion.md §6.2）。摆法存在这台手机上，跟着素材包走。
- **衣服和发饰**要看 Live2D 模型有没有能切换的部件，先查「Mao绒绒家园」这个模型的参数（§7）。
- 没有货币、商店、抽卡。

### 3.3 回忆

- **日记本**（§2.3）。
- **相册**：在小屋里拍一张，存舞台画面、她当时说的话、日期，存在这台手机上，能分享。
- **纪念日**：认识第 7、30、100、365 天；你的生日（她问一次，可以不说）；她的生日（素材包的 `character.json` 可以带）；春节、中秋这些节日。当天她的问候、潮水带来的东西和小组件都不一样。
- 菜单里显示「认识第 N 天」：从第一次见面算起的天数，不是连续签到，不会断。
- 小组件加一行：今天潮水带来了什么，还没捡的话写「沙地上有东西」。

## 4. 不做的，和做成选项的

**建议不做**：缺席时扣亲近度或心情、连签断了清零、卖惨的通知（「她等了你一整天」）、错过就永远没有的限时物件、付费加速。理由：

- 这些拉起来的是一时的数字，代价是内疚感。DSH Go 的用户多半是来干活的，被内疚推着走，常见的结果是关通知或者卸载。
- 《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行）禁止服务提供者「诱导情感依赖或者沉迷」，上面这几样正是它说的那类。它对开源、自带 Key 的客户端管到哪一步，还没确认（companion.md §7）。

这几样 owner 想要的话，也可以照下表的办法做成选项。

**做成选项，默认关**，想要的人自己开：

| 选项 | 开了以后 |
|---|---|
| 连续签到 | 菜单里显示连着来了几天，断了从 1 重新数；不影响亲近度和解锁 |
| 想你了 | 离开超过你设的天数，她发一条通知说想你 |
| 休息提醒 | 一次在小屋里待超过你设的时长，她提醒你歇一会儿 |
| 每日花费上限 | 日记、简报、主动开口这些她自己调模型的事，一天最多用多少 token |

## 5. 怎么看效果

- App 的匿名使用报告（share-links.md §15）按天、按安装去重，能算留存。现在的计数是对话轮次、语音、手机操控、分享、生成、插件，没有伙伴和酒馆。
- 加两个计数：`companion`（当天进小屋的次数）、`tavern`（酒馆的对话轮次）。要改三处：App 的 `UsageCount`、Worker 的 `services/share-worker/src/usage.ts`、`scripts/stats.sh`。
- **先改 Worker 再发 App。** Worker 现在对 `counts` 很严：多一个键、少一个键都整份拒掉。所以 Worker 先改成新键可有可无（缺了按 0），部署之后 App 再带上新键。合同仍是 v1。
- 看的东西：用过伙伴的安装和没用过的，7 日、30 日留存各是多少；每天进小屋的安装里，有多少天是只进了小屋。

## 6. 阶段

界面、舞台表演、小组件和通知归主线；规则层（潮水的掉落表、她自己的日子、解锁表、日记的提示词和记忆提议）和 Worker 的计数交给 Pro。

| 阶段 | 内容 |
|---|---|
| D1 | 不花 token 的：潮水和收藏册、进门问候带上今天的事、她自己的日子、认识第 N 天和纪念日、小组件那一行、使用报告的两个计数 |
| D2 | 日记本和交换日记、相册、每一档的解锁、装扮（小房子第 2 期） |
| D3 | 早安简报和「她」的通知频道、原生定时、主动开口；简报接上管家 |
| 随时 | §4 的四个选项 |

## 7. 待定

- **美术。** 贝壳、漂流瓶、小生物、节日物件、装扮件都要图，画风要和水下场景一致。可以让网页版 Pro 按现有场景统一出图。
- **模型部件。** 「Mao绒绒家园」的模型有哪些能切换的部件（衣服、发饰、配件），决定能不能做换装。
- **台词库。** 捡东西、她自己的日子、通知这些不调模型的台词，跟着素材包走，还是 App 自带一份通用的。
- **早安简报在后台能取到什么。** 主机连接在后台不一定活着，要看现在的保活（`PrivilegedKeepJob`）能不能顺带用。
- **酒馆的角色要不要也有这些。** 先只做伙伴；请进小屋的卡（roleplay.md §2.3）自动有。
