| 结论层 | 能支持的判断 | 不能推出的判断 |
|---|---|---|
| 源码 / 固定公开声明 | 调用条件、数据流、类型和精确接口 | 系统服务一定实现或设备一定允许 |
| Linux 实际执行 | 指定源、字节、时序及明确平台替身下的结果 | OH 内核、Ark VM、目标 native ABI 或手机能耗 |
| 公开 SDK 严格 ArkTS | 指定工程方法体、公开接口和准确编译产物通过 | 完整 Dart AOT/native 装配、签名或手机运行 |
