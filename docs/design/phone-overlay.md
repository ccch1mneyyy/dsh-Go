# 手机操控的悬浮条（小球 · 胶囊 · 卡片）

DSH 用无障碍服务操作手机时，浮在其他应用上面的控制条，以及沿屏幕边缘走的一道光。代码在 `app/android/app/src/main/kotlin/io/github/ccch1mneyyy/dsh_app/phone/a11y/`：`ControlOverlay.kt`（窗口、确认卡、交还卡、形态之间的编排、避让键盘和确认卡）、`OverlayCapsule.kt`（胶囊和卡片）、`OverlayBall.kt`（小球）、`OverlayLook.kt`（颜色、图形、标记）、`EdgeBeam.kt`（边缘流光）、`OverlayModel.kt`、`FoldClock.kt` 和 `EdgeBeamModel.kt`（纯 Kotlin 的状态、位置与尺寸，JVM 单测覆盖）。

## 0. 结论

一个控件，三档形态，是同一个物体在变形；它放在屏幕中下方，拇指够得着，也不压住应用自己的标题栏：

- **胶囊**（默认）：一行「正在做什么」+ 暂停 / 停止。实心表面，不变淡。
- **卡片**（点胶囊上那行字）：胶囊往上长出第二层——目标应用、免确认、最近几步、已解除限制、插话、收成小球。头部（连同停止键）留在胶囊原来的位置。
- **小球**（点胶囊左端的标记）：只说状态，贴边、可拖，闲置变淡。

控件在的时候，屏幕四周有一道很淡的流光沿边缘走（§12），告诉用户「手机正在被操作」；暂停时停成一圈静止的细边。

停止在任何形态下都一步可达：胶囊和卡片右端永远是**停止**；小球**按住 1 秒**直接停止（读屏有「停止 DSH 的操作」动作）。

## 1. 三档形态

| 形态 | 尺寸 | 内容 | 怎么进 / 出 |
|---|---|---|---|
| 小球 | 直径 48，窗口四周各留 10 给阴影；离屏幕边 12，默认在右侧、和胶囊同一高度（拖过之后记住拖到的位置） | 状态标记（见 §3），解除了限制时右上角一个砖红小点 | 点胶囊左端标记、卡片的「收成小球」；开了「闲置时自动收起」时胶囊闲置 3.5 s。点小球回到胶囊（不会直接到卡片） |
| 胶囊 | 高 48，宽跟着这行字：最窄 120，最宽「屏宽 − 24」且 ≤ 400，按 8 取整；水平居中，中心在安全区高度的 72% 处；离导航栏、键盘、确认卡至少 12 | 标记 · 这行字（前面可能有锁）· ⌃ · 暂停 · 停止 | 任务开始时出现；卡片闲置 8 s 收回；确认、交还、已停止把卡片收回胶囊 |
| 卡片 | 宽同胶囊最宽；高按内容（一般 300 左右）；从胶囊往上长，底边不动 | 头部和胶囊同一行，在最下面；上面：应用 · 免确认、最近几步、已解除限制、插话框、收成小球 | 点胶囊那行字；再点那行字、闲置 8 s、确认 / 交还 / 停止时收回胶囊；打字时一直开着 |

### 位置

- **胶囊**：窗口挂在底边上（`Gravity.BOTTOM`），胶囊中心 = 安全区顶 + 0.72 × 安全区高（1080×2400、状态栏 36 dp、导航栏 24 dp 的手机上约在屏幕 71% 处）。窗口变高（卡片）时底边不动，所以卡片向上长，头部和停止键原地不动。
- **避让**：键盘（任何应用的，或插话自己的）或底部确认卡出现时，胶囊沿 `glide` 240ms 移到它们上沿再上 12 dp 的地方，走了以后回来；再高也不会越过状态栏下 12 dp。键盘从服务的窗口列表里读（`TYPE_INPUT_METHOD`），确认卡读它自己窗口的高度。无障碍悬浮窗在输入法之上，不让开就会盖住键盘。
- **小球**：没被拖过时停在右侧、和胶囊中心同一高度；拖过就记住（跨任务）。确认卡或键盘出现时，停着的小球也抬到它们上面。
- 横屏同样按安全区高度的 72% 放；矮屏上卡片比胶囊上方的空间还高时，卡片顶部会被屏幕截掉（见 §11）。

所有形态一个圆角 24：胶囊两端、卡片四角、小球都是同一条曲线，变形时角不会重新弯折。卡片比页面规范里的卡片（20）略圆，是为了和胶囊端头连续。

### 胶囊的宽度

宽度跟着这一行变，但不跟着抖：更长的行立刻长宽（240ms，`glide`）；更短的行要持续 1.2 s 才收窄，而且只在窄了 24 dp 以上时收。智能体每秒在「正在看屏幕」和「点「…」」之间来回，宽度保持稳定。到最宽时末尾省略。

### 卡片的内容（从头部往上）

卡片向上长，内容按离头部的远近排：和这一行关系越近的越靠近头部（就是原来向下的卡片上下翻过来）。

1. 头部：和胶囊同一行，在卡片最下面；⌃ 转成 ⌄。
2. 应用 · 免确认（12，三级文字），紧贴在头部那行字上面。
3. 最近几步：最多 3 条（矮屏 1 条），新的在下（最靠近头部）；挂在标记上方的一条细时间线上。只记动作（点、输入、滚动、按键），不记「正在看屏幕」；和头部同一条不重复。
4. 已解除限制（有任一项解除时）：浅砖红底，「已解除限制」加粗，下一行是解除了哪几项，右侧「查看 ›」打开 `dshgo://open/phone-unlocks`。
5. 插话框：点一下才拿键盘（窗口此前不可聚焦）；有字时发送键变成主色圆。键盘出来时整个控件抬到键盘上面（§1 位置）。发送后收回胶囊，那一行显示「已发给 DSH：…」2.5 s。
6. 收成小球（卡片最上面）：附一行「按住小球 1 秒可直接停止」，教会小球的停止手势。

## 2. 信息层级

- **胶囊只说正在做的事。** 核心给的状态行是「免确认 · DSH 正在操作 · 点「发送」」，胶囊本身就是 DSH 的，所以显示「点「发送」」；前缀按核心自己的格式（`phone_waived_status`、`phone_acting`，App 语言）剥掉，换语言也对得上。「DSH 正在看屏幕」这类非动作行原样显示。
- **免确认**降到卡片的第一行。
- **已解除限制**不再在胶囊里占一段文字：胶囊里只在这行字前放一把砖红的开锁（14），小球右上角一个砖红小点；完整说明和入口在卡片里。
- 暂停时这一行是「已暂停」，暂停键变成主色的 ▶；等确认时是「等你在下方确认」，标记变成三点；停止后是「已停止」，按键收起，胶囊缩小，4 s 后整个离开。

## 4. 动效

都按系统动画缩放；「移除动画」时形态直接切换，呼吸停在满环。

| 变化 | 怎么动 | 时长 / 曲线 |
|---|---|---|
| 出现 | 淡入 + 下移 6 + 0.96 → 1 | 220ms，emphasized |
| 胶囊 → 卡片 | 同一个表面向上、向两边长到卡片大小，底边不动；头部那一行留在原处、跟着表面的宽度走，停止键贴着右端移动；第二层在后 70% 淡入并上移 6；⌃ 转到 ⌄ | 340ms，emphasized |
| 卡片 → 胶囊 | 反过来，表面收回底边上的胶囊，第二层在前 40% 淡出 | 340ms，emphasized |
| 胶囊 → 小球 | 表面收成离停靠侧较近那一端的圆（卡片则先收成头部那一端的圆，在卡片底部），行内容钉在原位被轮廓裁掉、前 40% 淡出；收成圆后小球在同一位置接手，标记淡入，再滑到停靠位置（默认就在同一高度，只横着滑） | 340ms + 260ms glide |
| 小球 → 胶囊 | 小球滑回胶囊端头、标记淡出；胶囊窗口在小球出发时就以透明的圆准备好，到达后从圆长回胶囊，行内容后半段淡入 | 220ms glide + 340ms |
| 让开键盘 / 确认卡 | 胶囊窗口整体上移到它们上面，走了以后回来；停着的小球一起 | 240ms glide |
| 边缘流光 | 见 §12：淡入 0.6 s、淡出 0.5 s（CSS ease），暂停时 0.5 s 内慢下来停成细边 | |
| 这一行换字 | 旧字 70ms 淡出、新字 160ms 淡入；宽度见 §1 | |
| 标记换状态、暂停 ↔ 继续 | 交叉淡变 + 0.7 → 1 | 160ms |
| 小球闲置 | 整个小球一起淡到「闲置时不透明度」；一碰 120ms 回满 | 400ms |

## 6. 停止：任何形态一步可达

DSH 在动用户的手机，任何时候都要能马上停下：

1. **胶囊和卡片**：停止键永远在头部最右端，两种形态同一个位置、同一个样子，不进菜单、不需要先展开。停止键不做防注入的拦截（停下是安全方向），但智能体注入手势时所有悬浮窗都不可触摸，它点不到。
2. **小球**：**按住 1 秒停止**。按下 0.3 s 后（短于系统长按的 0.4 s）开始沿标记的环画一圈砖红进度，满一圈（共 1 s）时震动一下并停止；中途松手取消（既不停止也不算点按）；手指移动超过系统的触摸阈值就是拖动，永远不会变成停止。计时按真实时钟用帧回调推进，不依赖动画，所以「移除动画」时同样有效；如果主线程忙到错过那一帧，松手时也会补上停止。小球也可以**点一下展开**，停止就在胶囊右端。
3. **读屏**：小球带一个「停止 DSH 的操作」自定义动作（TalkBack 的操作菜单里），一步停止。
4. 其他入口不变：通知栏引擎通知的「停止操作」、熄屏、锁屏、无障碍服务断开。

停止后胶囊显示「已停止」（小球显示方块），4 s 内核心没有新的状态就整个离开。

## 7. 闲置与设置

- **闲置时不透明度**（设置 › 手机操控 › 悬浮条，30–100%，默认 70%）现在只作用于**小球**：小球 3 s 没人碰就整体淡到这个不透明度。胶囊和卡片不变淡——它们承载这一行字，半透明会让字压在页面上读不清；想让它们让开就收成小球。
- **闲置时自动收起**：胶囊闲置 3.5 s 收成小球；确认、交还、插话时自动展开。
- 动作期间屏幕常亮（`FLAG_KEEP_SCREEN_ON`），这一轮回复结束时控件一定关闭。

## 8. 与确认卡、交还卡

- 确认卡在屏幕底部，胶囊在中下方。确认出现时卡片先收回胶囊（避免两张卡抢注意力），胶囊显示「等你在下方确认」并移到确认卡上沿再上 12 dp 处，两者永不重叠，「等你在下方确认」就在确认卡正上方，读起来是一句话；确认结束后胶囊回到原位。自动收起的小球会展开，手动收起的小球保持（停着的也抬到确认卡上面），标记变成三点。
- 不选「确认卡出现时胶囊去顶部」：胶囊跳到屏幕另一头，用户的视线和停止键都要跟着找。贴在确认卡上面，停止键离确认卡的「停止」也近。
- 旧路径的交还卡在顶部（不变），出现时胶囊、小球和边缘流光都让开，结束后回到胶囊。
- 确认卡、交还卡（`ControlOverlay` 里的旧路径）换成了同一套实心表面和颜色；共享的 `PhonePromptUi` 卡片没有改动。

## 9. 无障碍

- 每个按键有描述：标记「收成小球」，这一行读出当前内容并带「展开详情 / 收起详情」的点按说明，暂停「暂停 DSH 的操作」/「继续让 DSH 操作」，停止「停止 DSH 的操作」，小球按状态读「DSH 正在操作手机，点按展开，按住停止」等。按键角色是按钮。
- 暂停、继续、停止时朗读一次新状态；普通状态行不朗读（每秒都在变）。
- 文案都在 `res/values*/phone_a11y_strings.xml`，按 App 语言取（`AppStrings`）。

- 模拟器（API 35，1080×2400，420 dpi）：debug 探针 `A11yProbe` 的 `form` / `press` / `unlocks` / `app` / `freeze` / `state` 命令能不经过完整任务调出每种形态和状态，深浅色、横屏、关闭动画、插话打字、按住停止都在模拟器上看过（位置改到中下方之前；改后还没在模拟器上看）。
- 边缘流光：用逐像素复刻 `EdgeBeam.kt` 画法的脚本出了 1080×2400 的预览帧（深浅色、运行、暂停）。

## 11. 需要真机确认

- 国产 ROM（vivo OriginOS 等）上 `TYPE_ACCESSIBILITY_OVERLAY` 的阴影、圆角裁切和窗口尺寸变化是否和原生一致；挂底边的窗口变高时底边是否真的不动（卡片展开那一帧有没有跳）。
- 小球贴边、拖动与系统边缘返回手势的冲突。
- 按住停止的手感（1 s 是否合适），以及 ROM 是否拦截悬浮窗上的振动。
- 小球被拖到底部时仍可能盖住底部确认卡的按钮（停着的小球会抬上去，正在拖的不会）。
- 各家输入法窗口在无障碍窗口列表里的位置是否准（悬浮键盘、分体键盘只取最上沿）；横屏矮屏时卡片顶部被截。
- 边缘流光：真机的圆角半径（API 31+ 读系统，以下按 28 dp）、刘海和挖孔附近的观感；全屏一层着色器在中低端机上的耗电与掉帧；截图和注入手势时隐藏是否干净（截图里不能有）、频繁隐藏 / 出现会不会显得闪；Android 8.x 只画细边。

## 12. 边缘流光

控件在屏幕上、任务在跑时，屏幕四周有一道光沿边缘慢慢走一圈：Libraries.dev Border beam 的 `md` 类型（App 里的 Dart 移植在 `app/lib/ui/fx/beam/`），同一套数字，从卡片放大到整块屏幕。代码：`EdgeBeam.kt`（窗口和画法）、`EdgeBeamModel.kt`（数字、配色、时钟，`EdgeBeamModelTest`）。

| 项 | 规定 |
|---|---|
| 窗口 | 服务自己的全屏 `TYPE_ACCESSIBILITY_OVERLAY`：`FLAG_NOT_TOUCHABLE \| NOT_FOCUSABLE \| LAYOUT_IN_SCREEN \| LAYOUT_NO_LIMITS`，刘海模式 ALWAYS，盖住状态栏和导航栏；永远不接触摸、不拿焦点。比胶囊窗口先加，所以在控件下面 |
| 形状 | 沿屏幕自己的圆角走：API 31+ 读 `WindowInsets.getRoundedCorner`（四个角分别取），更早按 28 dp |
| 层 | 和 `md` 一样三层：内侧光（9 个色块 90% 大小、透明度 0.45，被转动的锥形窗口和 28 dp 的边缘渐隐遮住，加一道 9 / 1 dp 的内阴影），1 dp 的边（色块 + 白色高光，同一窗口），光晕（锥形光晕图案；原版是先模糊再裁到 1 px 边，边上只剩一半，所以按 0.5 画） |
| 透明度 | 深色：边 0.26、内侧 0.42、光晕 0.24；浅色：0.12、0.26、0.34（原版 `sizeThemePresets.md`）；滤镜 hue-rotate → brightness 1.3 → saturate 1.2 / 1.5，合成一个矩阵（作者原生移植的做法） |
| 配色 | 跟 App 的主色：读 Dart 端已经写给原生的强调色（`appearance.notify_color`，`ThemeAccent`），取它左右相邻的九个色相、饱和度压到 0.4–0.6（和 Dart 移植的 `BeamPalette.fromSeed` 一样）；没写过时用雾蓝。深浅色跟系统夜间模式（和胶囊一样：它画在别的应用上面） |
| 尺度 | 色块按屏幕和作者 350×140 参考尺寸的比例分轴放大（作者 pulse-outside 的规则，夹在 0.35–4）；锥形渐变先压成正方形再转，转一圈时光在长边和短边上走得一样匀，不在角上冲 |
| 速度 | 原版 1.96 s 绕一张卡片；屏幕按周长同比放大，再慢一半（整圈边在快速流动会像警报）：1080×2400 的手机上约 8 s 一圈，限制在 6–12 s；色相 ±30° 12 s 往返。最多 60 fps，120 Hz 屏上也是 |
| 出现 / 离开 | 任务开始、控件出现时淡入 0.6 s；已停止、任务结束、交还卡出现时淡出 0.5 s（CSS ease），淡完才移除窗口 |
| 暂停 | 0.5 s 内慢下来，停成一圈静止的细边（边的颜色，透明度为平时的 0.6），不再请求帧；继续时再走 |
| 移除动画 | 系统动画缩放为 0 时只有那圈静止的细边，开关不渐变 |
| 截图、注入手势 | 每次截图（`hideForCapture`）和每次注入手势（`setPassThrough`）期间都设成 INVISIBLE：不进模型的截图；它本来就不可触摸，手势也不会被它挡住。它的窗口算 DSH 自己的窗口（`ownsWindow`、截图的隐藏回执），显隐不会让驱动以为换了页面 |
| 开销 | 每帧只改三个锥形渐变的矩阵和画笔透明度，不分配对象；内侧光是一条路径上的一个组合着色器（9 个径向渐变 + 锥形 + 两个线性），只画屏幕边上 28 dp 宽的一圈 |
| Android 8.x | 组合着色器在旧硬件渲染上画不对：只画边上的锥形窗口和高光，没有内侧光和内阴影 |

预览：`EdgeBeam.kt` 的画法逐像素复刻成脚本，在 1080×2400 的圆角手机画面上出了深浅色、运行和暂停的帧，以及控件新位置的示意（胶囊、向上长的卡片、确认卡上方的胶囊）。
