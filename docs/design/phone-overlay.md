# 手机操控的悬浮条（小球 · 胶囊 · 卡片）

DSH 用无障碍服务操作手机时，浮在其他应用上面的控制条，以及贴着屏幕边缘的一圈色带。代码在 `app/android/app/src/main/kotlin/io/github/ccch1mneyyy/dsh_app/phone/a11y/`：`ControlOverlay.kt`（窗口、确认卡、交还卡、形态之间的编排、拖动、避让键盘和确认卡）、`OverlayCapsule.kt`（胶囊和卡片）、`OverlayBall.kt`（小球）、`OverlayLook.kt`（颜色、图形、标记）、`EdgeBeam.kt`（边缘色带）、`OverlayModel.kt`、`FoldClock.kt`、`OverlayPrefs.kt` 和 `EdgeBeamModel.kt`（纯 Kotlin 的状态、位置与尺寸，JVM 单测覆盖）。

## 0. 结论

一个控件，三档形态，是同一个物体在变形。它不能挡着用户自己用手机：默认放在屏幕中下方，拇指够得着，也不压住应用自己的标题栏；用户可以把它拖到任意高度、靠左 / 居中 / 靠右，或拖出屏幕边收成小球；闲置时自动收成贴边、半藏的小球。

- **胶囊**：一行「正在做什么」+ 暂停 / 停止。实心表面，不变淡。任务开始时出现，闲置 3.5 s 收成小球（「闲置时自动收起」默认开）。
- **卡片**（点胶囊上那行字）：胶囊往上长出第二层——目标应用、免确认、最近几步、已解除限制、插话、收成小球。头部（连同停止键）留在胶囊原来的位置。
- **小球**（点胶囊左端的标记、拖出屏幕边，或闲置自动收起）：只说状态，贴边、可拖；闲置时变淡并滑出去半个，只露一半。

控件在的时候，屏幕四周一直有一圈很淡、不均匀的色带贴着边缘（§12），告诉用户「手机正在被操作」，不在屏幕中间做任何事；暂停时收成一条静止的细边。

停止在任何形态下都一步可达：胶囊和卡片右端永远是**停止**；小球**按住 1 秒**直接停止（读屏有「停止 DSH 的操作」动作）。

## 1. 三档形态

| 形态 | 尺寸 | 内容 | 怎么进 / 出 |
|---|---|---|---|
| 小球 | 直径 48，窗口四周各留 10 给阴影；离屏幕边 12，默认在右侧、和胶囊同一高度（拖过之后记住拖到的位置）；闲置时滑出去半个（§1 位置） | 状态标记（见 §3），解除了限制时右上角一个砖红小点 | 点胶囊左端标记、卡片的「收成小球」、把胶囊拖出屏幕边；「闲置时自动收起」（默认开）时胶囊闲置 3.5 s。点小球回到胶囊（不会直接到卡片） |
| 胶囊 | 高 48，宽跟着这行字：最窄 120，最宽「屏宽 − 24」且 ≤ 400，按 8 取整；默认水平居中、中心在安全区高度的 72% 处，拖过之后在用户放下的高度和锚点；离状态栏、导航栏、键盘、确认卡至少 12 | 标记 · 这行字（前面可能有锁）· ⌃ · 暂停 · 停止 | 任务开始时出现；卡片闲置 8 s 收回；确认、交还、已停止把卡片收回胶囊 |
| 卡片 | 宽同胶囊最宽；高按内容（一般 300 左右）；从胶囊往上长，底边不动 | 头部和胶囊同一行，在最下面；上面：应用 · 免确认、最近几步、已解除限制、插话框、收成小球 | 点胶囊那行字；再点那行字、闲置 8 s、确认 / 交还 / 停止时收回胶囊；打字时一直开着 |

### 位置

- **胶囊**：窗口挂在底边上（`Gravity.BOTTOM`），从左边定位（`Gravity.LEFT`，x 由 `CapsulePlacement` 算）。位置是 `CapsuleSpot`：中心高度存成安全区高度的比例（默认 0.72，1080×2400、状态栏 36 dp、导航栏 24 dp 的手机上约在屏幕 71% 处），横向是三个锚点之一——靠左（胶囊左端离安全区左边 12 dp）、居中（在整块屏幕上居中，默认）、靠右（右端离安全区右边 12 dp）。拖过之后存进悬浮条的偏好文件（`dsh_phone_overlay`，和小球的停靠位置在一起），跨任务记住；横屏用同一个比例。窗口变高（卡片）时底边不动，所以卡片向上长，头部和停止键原地不动；宽度变化时从锚点那一侧长（靠左的左端不动，靠右的右端不动，居中的两边一起）。
- **卡片的横向**：卡片宽是胶囊的最宽值，胶囊在卡片里贴着锚点那一侧（靠左时卡片左边和胶囊左端对齐，靠右时右边对齐，居中时居中），所以头部不挪，卡片也不会出屏。
- **卡片的纵向**：卡片最高到状态栏下 12 dp（`CapsulePlacement.cardRoom`）。胶囊被拖得很靠上、上方放不下卡片时，展开的同时胶囊沿 `glide` 240ms 下移到刚好放得下，收回后回到原位。键盘也在、仍然放不下时，头部和停止键留在键盘上方，第二层在剩下的高度里滚动，聚焦的插话框自己滚进视野。
- **避让**：键盘（任何应用的，或插话自己的）或底部确认卡出现时，胶囊沿 `glide` 240ms 移到它们上沿再上 12 dp 的地方，走了以后回来；对用户拖到的位置同样生效，本来就在它们上面的不动；再高也不会越过状态栏下 12 dp。键盘从服务的窗口列表里读（`TYPE_INPUT_METHOD`），确认卡读它自己窗口的高度。无障碍悬浮窗在输入法之上，不让开就会盖住键盘。
- **小球**：没被拖过时停在右侧、和胶囊中心同一高度；拖过、或由拖出屏幕边的胶囊收成，就记住那一侧和高度（跨任务）。确认卡或键盘出现时，停着的小球也抬到它们上面。
- **小球半藏**：小球闲置 3 s 后，除了变淡，再向停靠那一侧滑出去，直到球心落在安全区边上（屏幕边；横屏导航栏在侧边时是导航栏的内沿），只露出半个球。小球窗口整块（球 + 四周 10 dp）都接触摸，半藏时屏幕上还剩 34 × 68 dp 可点；窗口登记为系统边缘返回手势的排除区（API 29+），从边上往里拖不会变成返回。

所有形态一个圆角 24：胶囊两端、卡片四角、小球都是同一条曲线，变形时角不会重新弯折。卡片比页面规范里的卡片（20）略圆，是为了和胶囊端头连续。

### 胶囊的宽度

宽度跟着这一行变，但不跟着抖：更长的行立刻长宽（240ms，`glide`）；更短的行要持续 1.2 s 才收窄，而且只在窄了 24 dp 以上时收。智能体每秒在「正在看屏幕」和「点「…」」之间来回，宽度保持稳定。到最宽时末尾省略。

### 卡片的内容（从头部往上）

卡片向上长，内容按离头部的远近排：和这一行关系越近的越靠近头部（就是原来向下的卡片上下翻过来）。

1. 头部：和胶囊同一行，在卡片最下面；⌃ 转成 ⌄。
2. 应用 · 免确认（12，三级文字），紧贴在头部那行字上面。
3. 最近几步：最多 3 条（矮屏 1 条），新的在下（最靠近头部）；挂在标记上方的一条细时间线上。只记动作（点、输入、滚动、按键），不记「正在看屏幕」；和头部同一条不重复。
4. 已解除限制（有任一项解除时）：浅砖红底，「已解除限制」加粗，下一行是解除了哪几项，右侧「查看 ›」打开 `dshgo://open/phone-unlocks`。
5. 插话框：点一下才拿键盘（窗口此前不可聚焦）；有字时发送键变成主色圆。键盘出来时整个控件抬到键盘上面（§1 位置）。发送后收回胶囊，那一行显示「已发给 DSH：…」2.5 s。
6. 收成小球（卡片最上面）：附一行「按住小球 1 秒可直接停止」，教会小球的停止手势。

## 2. 信息层级

- **胶囊只说正在做的事。** 核心给的状态行是「免确认 · DSH 正在操作 · 点「发送」」，胶囊本身就是 DSH 的，所以显示「点「发送」」；前缀按核心自己的格式（`phone_waived_status`、`phone_acting`，App 语言）剥掉，换语言也对得上。「DSH 正在看屏幕」这类非动作行原样显示。
- **免确认**降到卡片的第一行。
- **已解除限制**不再在胶囊里占一段文字：胶囊里只在这行字前放一把砖红的开锁（14），小球右上角一个砖红小点；完整说明和入口在卡片里。
- 暂停时这一行是「已暂停」，暂停键变成主色的 ▶；等确认时是「等你在下方确认」，标记变成三点；停止后是「已停止」，按键收起，胶囊缩小，4 s 后整个离开。

## 6. 停止：任何形态一步可达

DSH 在动用户的手机，任何时候都要能马上停下：

1. **胶囊和卡片**：停止键永远在头部最右端，两种形态同一个位置、同一个样子，不进菜单、不需要先展开。停止键不做防注入的拦截（停下是安全方向），但智能体注入手势时所有悬浮窗都不可触摸，它点不到。
2. **小球**：**按住 1 秒停止**。按下 0.3 s 后（短于系统长按的 0.4 s）开始沿标记的环画一圈砖红进度，满一圈（共 1 s）时震动一下并停止；中途松手取消（既不停止也不算点按）；手指移动超过系统的触摸阈值就是拖动，永远不会变成停止。计时按真实时钟用帧回调推进，不依赖动画，所以「移除动画」时同样有效；如果主线程忙到错过那一帧，松手时也会补上停止。小球也可以**点一下展开**，停止就在胶囊右端。
3. **读屏**：小球带一个「停止 DSH 的操作」自定义动作（TalkBack 的操作菜单里），一步停止。
4. 其他入口不变：通知栏引擎通知的「停止操作」、熄屏、锁屏、无障碍服务断开。

停止后胶囊显示「已停止」（小球显示方块），4 s 内核心没有新的状态就整个离开。

## 7. 闲置与设置

- **闲置时不透明度**（设置 › 手机操控 › 悬浮条，30–100%，默认 70%）只作用于**小球**：小球 3 s 没人碰就整体淡到这个不透明度，并滑出去半个。胶囊和卡片不变淡——它们承载这一行字，半透明会让字压在页面上读不清；想让它们让开就收成小球或拖开。
- **闲置时自动收起**（默认开）：胶囊在任务开始时出现，闲置 3.5 s 收成贴边小球；确认、交还、插话时自动展开，小球先完整回来。没设过这个偏好的用户按开处理，显式关过的保持关；设置页显示的默认态同样是开（Dart 端 `PhoneOverlayPrefs.defaultAutoCollapse`）。
- 胶囊拖到的位置和小球的停靠位置不在设置页里，拖动即设置。
- 动作期间屏幕常亮（`FLAG_KEEP_SCREEN_ON`），这一轮回复结束时控件一定关闭。

## 8. 与确认卡、交还卡

- 确认卡在屏幕底部，胶囊在中下方。确认出现时卡片先收回胶囊（避免两张卡抢注意力），胶囊显示「等你在下方确认」并移到确认卡上沿再上 12 dp 处，两者永不重叠，「等你在下方确认」就在确认卡正上方，读起来是一句话；确认结束后胶囊回到原位。自动收起的小球会展开，手动收起的小球保持（停着的也抬到确认卡上面），标记变成三点。
- 不选「确认卡出现时胶囊去顶部」：胶囊跳到屏幕另一头，用户的视线和停止键都要跟着找。贴在确认卡上面，停止键离确认卡的「停止」也近。
- 旧路径的交还卡在顶部（不变），出现时胶囊、小球和边缘色带都让开，结束后回到胶囊。
- 确认卡、交还卡（`ControlOverlay` 里的旧路径）换成了同一套实心表面和颜色；共享的 `PhonePromptUi` 卡片没有改动。

## 9. 无障碍

- 每个按键有描述：标记「收成小球」，这一行读出当前内容并带「展开详情 / 收起详情」的点按说明，暂停「暂停 DSH 的操作」/「继续让 DSH 操作」，停止「停止 DSH 的操作」，小球按状态读「DSH 正在操作手机，点按展开，按住停止」等。按键角色是按钮。
- 暂停、继续、停止时朗读一次新状态；普通状态行不朗读（每秒都在变）。
- 文案都在 `res/values*/phone_a11y_strings.xml`，按 App 语言取（`AppStrings`）。

## 11. 需要真机确认

- 国产 ROM（vivo OriginOS 等）上 `TYPE_ACCESSIBILITY_OVERLAY` 的阴影、圆角裁切和窗口尺寸变化是否和原生一致；挂底边的窗口变高时底边是否真的不动（卡片展开那一帧有没有跳）。
- 小球贴边、半藏时与系统边缘返回手势的冲突（已登记排除区，各家 ROM 是否认）；半藏的半个球在曲面屏边上是否看得见、点得中。
- 胶囊拖动的手感：触摸阈值、拖出屏幕边 32 dp 收成小球是否容易误触或太难触发；卡片开着时从头部拖动、收回动画中的跟手；拖动时与正在注入的手势（窗口变不可触摸）交错的情况。
- `FLAG_LAYOUT_NO_LIMITS` 让胶囊、小球窗口出屏，国产 ROM 是否照办（不照办时出边那一段会被夹回屏幕里）。
- 按住停止的手感（1 s 是否合适），以及 ROM 是否拦截悬浮窗上的振动。
- 小球被拖到底部时仍可能盖住底部确认卡的按钮（停着的小球会抬上去，正在拖的不会）。
- 各家输入法窗口在无障碍窗口列表里的位置是否准（悬浮键盘、分体键盘只取最上沿）；横屏加键盘时卡片第二层滚动的手感。
- 边缘色带：浅色下 0.26 的透明度在白底上是否看得出来（预览里偏淡）、深色下是否抢戏；真机的圆角半径（API 31+ 读系统，取四角最大值，以下按 28 dp）、刘海和挖孔附近的观感；AGSL 着色器在中低端机上的耗电与掉帧（每帧约 96 dp 宽的一圈、30 fps）；截图和注入手势时隐藏是否干净（截图里不能有）、频繁隐藏 / 出现会不会显得闪；Android 9–12 的模糊描边降级、Android 8.x 只画细边的观感。

## 12. 边缘色带

控件在屏幕上、任务在跑时，屏幕四周一直有一圈柔和的色带贴着屏幕轮廓（含圆角），向屏幕内侧渐隐到 0：Libraries.dev Distortion waves 留在屏幕边缘的那部分颜色（着色器 `waveBand` 的 rim 和 `WaveRim.lumps`），单独拿出来、钉在原地。屏幕中间什么都不做：不扭曲底下应用的内容（我们没有它的像素），没有扫过全屏的波前、粒子，没有色相往返。代码：`EdgeBeam.kt`（窗口和画法）、`EdgeBeamModel.kt`（数字、鼓包、配色、时钟，`EdgeBeamModelTest`）。

| 项 | 规定 |
|---|---|
| 窗口 | 服务自己的全屏 `TYPE_ACCESSIBILITY_OVERLAY`：`FLAG_NOT_TOUCHABLE \| NOT_FOCUSABLE \| LAYOUT_IN_SCREEN \| LAYOUT_NO_LIMITS`，刘海模式 ALWAYS，盖住状态栏和导航栏；永远不接触摸、不拿焦点。比胶囊窗口先加，所以在控件下面 |
| 形状 | 沿屏幕自己的圆角：API 31+ 读 `WindowInsets.getRoundedCorner`（取四角最大值），更早按 28 dp；距离用圆角矩形的有符号距离场，位置按参考的 `perimeterAt`（从顶边中点顺时针量的周长坐标） |
| 宽度 | 参考 Edges 的默认 `rimWidth` 14 dp：在某处厚度为 t 时，离边 d 的不透明度是 exp(−(d / (14 dp × t))²)。只画离边 6.9 × 14 dp（约 96 dp）以内的一圈，最后 20% 平滑降到 0 |
| 不均匀 | `WaveRim.lumps` 的 7 个鼓包（`pulse` 恒为 0）：各自的位置、长度（周长 / 7 × 0.2–0.45）、深度（0.2–2.8）由固定散列给出，每次都一样；厚度 = (0.08 + Σ 深度 × exp(−(距离 / 长度)²)) / 1.0498，平均约 1，最薄处约 0.08，最厚约 2.4（呼吸到最大时 ≤ 2.9）。没有一处是空的 |
| 速度 | 参考的漂移（±22 pt/s）和呼吸（sin(t × (1.1–2.3))，±25%）都放慢到一半：鼓包沿边每秒漂 0.7–7 dp，呼吸周期约 5.5–11 s。两秒之间几乎看不出变化，是「安静地在那儿」，不是在流动。最多 30 fps |
| 透明度 | 边上的峰值：深色 0.42、浅色 0.26（Border beam `md` 内侧光的量级，作为上限）；暂停时的细边深色 0.26、浅色 0.16 |
| 配色 | 跟 App 的主色：读 Dart 端已经写给原生的强调色（`appearance.notify_color`，`ThemeAccent`），取它左右相邻的九个色相、饱和度压到 0.4–0.6、明度 0.58–0.70（和 Dart 移植的 `BeamPalette.fromSeed` 一样），沿周长铺一圈，相邻两色平滑过渡，不随时间变；没写过时用雾蓝。深浅色跟系统夜间模式（和胶囊一样：它画在别的应用上面） |
| 出现 / 离开 | 任务开始、控件出现时淡入 0.6 s；已停止、任务结束、交还卡出现时淡出 0.5 s（CSS ease），淡完才移除窗口 |
| 暂停 | 0.5 s 内鼓包慢下来停住，色带收成一条静止的细边（同样的高斯渐隐，3 dp），不再请求帧；继续时再展开、再漂 |
| 移除动画 | 系统动画缩放为 0 时色带不动（鼓包停在初始位置、不呼吸）；暂停 / 继续、出现 / 离开直接切换 |
| 截图、注入手势 | 每次截图（`hideForCapture`）和每次注入手势（`setPassThrough`）期间都设成 INVISIBLE：不进模型的截图；它本来就不可触摸，手势也不会被它挡住。它的窗口算 DSH 自己的窗口（`ownsWindow`、截图的隐藏回执），显隐不会让驱动以为换了页面 |
| 画法与开销（Android 13+） | 一条路径（屏幕圆角矩形减去向内 96 dp 的矩形）上一个 AGSL `RuntimeShader`：每个像素算距离、周长坐标、7 个鼓包的厚度和颜色。每帧只在主线程算 7 个鼓包写进同一个数组，更新两个 uniform 和画笔透明度，不分配对象 |
| Android 9–12 | 没有 AGSL（13+ 上系统的着色器编译器拒绝这段 AGSL 时也走这里，不让无障碍服务崩掉）：一圈均匀、静止的色带——沿屏幕轮廓描一道 28 dp 宽的边、14 dp 的模糊（`BlurMaskFilter`），颜色是同一套九色的扫描渐变；没有鼓包。暂停时换成 3 dp 的细边 |
| Android 8.x | 硬件渲染不支持模糊：只画 3 dp 的细边（运行和暂停一样） |

预览：`EdgeBeam.kt` 的着色器逐像素复刻成脚本，在 1080×2400、圆角 110 px 的手机画面上，垫着白底和深底的假列表应用，出了深浅色 × 运行 / 暂停的帧，以及运行态相隔 2 s 的两帧。
