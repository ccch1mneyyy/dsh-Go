# 酒馆：优化排期

> 2026-11-10。来源是另一个会话写的优化技术文档（基线 `feat/roleplay` 的 f0bd262a，参考了 [bychv/dsh-preset-enhance](https://github.com/bychv/dsh-preset-enhance) 0.3.7-rc.1）。owner 对它的三项决定说「按照你的设计来」（下面 §1）。这里是对过当前代码（4cff2d12）之后的版本：已经做了的划掉，做法不同的以代码为准。分工照总纲：界面归主线，`packages/dsh_tavern` 归 Pro（写进 tavern2 的 ADDENDUM-04）。

## 1. 已定的三件事

1. **渲染分三级**，不一步到整页画布：
   - 0 原生：经显示正则后没有 HTML、卡不带脚本。
   - 1 岛屿：某条消息带 HTML、`<style>` 或前端代码块时，只这一条嵌一个高度自适应的沙箱 WebView。
   - 2 整页画布：卡带内嵌脚本、要酒馆助手接口，或样式跨消息选 `#chat .mes`。就是 [roleplay-ui.md](roleplay-ui.md) §3 原来写的那块画布。

   级别由导入体检定，角色页能改。先做 1，2 和酒馆助手、MVU 一起做。
2. **酒馆首页拆成四个板块**：书架、对话、资源库、我的（§4）。
3. **带预填充的回合不挂工具**。状态更新交给回合后的整理者；用文本协议模拟工具调用只做成实验开关。

## 3. 分期

「引擎」一列是 Pro 的活，编号对应 ADDENDUM-04；「App」一列是主线的。

### P0

| 项 | 引擎 | App |
|---|---|---|
| 会让整回合失败的硬伤 | T19：组装器字段类型宽容（数字写成字符串不再抛错）、`prompt_order` 选组（100001，然后是第一个非空组）、绑定的世界书缺失时跳过、数据库升级机制 | 无 |
| 错误和协议 | T19：402 和 400 分开报，`finish_reason` 为 length 或 content_filter 时带给 App，还没收到内容前自动重试 | 截断时给「接着写」，被过滤、余额不足各有提示 |
| 预设 | T20：导入（ST JSON 和 `.dsh-preset.json`）、预设库、按对话选、改顺序、改参数、导出、预填充目标 | 预设库、对话里的选择器、详情页（顺序、参数、预填充） |
| 正则和世界书 | T21：显示接口加 Isolate 和超时、导入时试编译、全局正则库、独立世界书导入和四处绑定 | 资源库里的正则和世界书列表、绑定入口；消息按显示正则渲染 |
| 导入体检 | T22：卡、预设、世界书、正则导入时出结构化结果，存下来 | 体检页，角色页常驻入口 |
| 性能 | T23：流式时少落盘（只写正文、间隔 500 毫秒，检视数据和全文索引等结束再写），`_historyTo` 改成一条查询，宏环境一回合只建一次，正则编译结果缓存，角色库只读索引 | 流式文本只让在写的那条重画；列表改懒加载，每条加 `RepaintBoundary`；往上翻按游标取 |
| 对话操作 | T24：离开对话页后回合继续，回来能接上；删除先软删、可撤销；对话内搜索；整库备份和恢复 | 离页不停；删除后有撤销条，一次删 10 条以上先确认；每条回复下方显示用量和费用（可关）；备份恢复页 |

### P1

- 岛屿渲染（级别 1）和防护开关。
- 首页四板块、角色页重排（「继续上次」作主按钮；分页签：对话、设定、配置、体检）、设置重组。
- 舞台面板加「本局」页。
- 分支树和书签、对话内搜索。T16 的世界书编辑、删除单条、以旁白身份发、只发不回接上。
- 视觉小说：表情图（T16f）、超长段落自动分页、输入区收起、记录页跟随主题。
- 小说排版：段首缩进、沉浸阅读、分章。
- 流式观感：
  - 思考计时，超过 20 秒可「跳过思考」；
  - 第一个字到之前显示「正在输入」；
  - 你往上翻时，回复写完不跳到底部。
- 输入区：
  - 快速回复横滑，末尾放「全部」；
  - 空输入直接发送 = 让角色接着说；
  - 有字时「接着写」变成「润色」。
- 新手：没有密钥时能离线翻示范卡的开场白，输入区写「填入密钥后开始」。
- 引擎搬进 Isolate（先量再定）、缓存友好排序、费用估算、滚动摘要、自定义端点、辅助模型。

### P2

- 整页画布（级别 2）、酒馆助手接口、内嵌脚本、MVU。
- 斜杠命令、ST 快速回复集、群聊。
- 增强层其余部分：状态（T17）、导演（T18）、工具、做卡助手、玩法包。

## 4. 首页四板块

| 板块 | 内容 |
|---|---|
| 书架 | 角色网格；排序（最近、名称、导入时间）、收藏置顶；标签筛选一直显示；多选批量删除和导出 |
| 对话 | 全部对话按时间排，带头像、最后一句和条数，能搜 |
| 资源库 | 预设、世界书、正则、人设、快速回复 |
| 我的 | 酒馆设置、备份和恢复、用量 |

导入走同一个入口，自动认出文件是卡、预设、世界书、正则、快速回复集还是聊天记录，送进对应的库，然后打开体检页。空状态加第三个入口「自己写一个角色」。
