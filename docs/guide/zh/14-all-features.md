# 全部功能

网页版的功能在手机上也能找到：对话列表底部的圆键打开**全部功能**，对话里也可以输入 `/features`。

<!-- nav: chatChats,hubSettingsAllFeatures -->
`对话列表 › 全部功能`

页面按组排列：当前对话、自动化、插件、社区与分享、工具、设置。最后一组是设置的快捷方式，末尾是全部设置。

## 当前对话

这些都要先打开一个对话，否则会提示**还没打开对话**：

- 对话详情：轨迹、改动、文件、进度、上下文和子代理，一页看完。
- 产出的文件：这段对话交付的文件，能预览、分享和保存。
- 文件：这段对话工作区里的文件，见[文件与工作区](17-workspaces.md)。
- 终端：工作区里的终端，见[终端](16-terminal.md)。
- 导出对话日志：把整个对话打包成 ZIP。
- 后台任务：查看输出、停止。
- 计划与目标、技能、子代理、引用文件和对话。

## 其他分组

- 自动化：自动化任务，见[自动化任务](18-schedules.md)。
- 插件：已安装与插件市场；带原生界面的插件会在组末尾追加自己的面板。
- 社区与分享：论坛、社区、DS Bot、分享配置。分享配置可以勾选设置、插件、技能和个人偏好，打成链接、二维码或文件。
- 工具：搜索对话、工作区、网页版。
- 设置：和设置页是同一批页面、同一个名字，只是这里也能进。
