# 酒馆

酒馆是 App 里的角色扮演区：导入 SillyTavern 的角色卡，和角色聊天或听一段故事。角色卡、对话和酒馆设置只存在这台手机上，用你在设置里填的 DeepSeek API Key 直接调模型，不需要装本机运行环境，也不用连远程主机。

## 进入酒馆

<!-- nav: chatChats,modeKeyTooltip,tavernTitle -->
`对话列表 › 切换模式 › 酒馆`

点对话列表顶部的**切换模式**键，在**模式**里选**酒馆**；返回键回到工作。把**启动时进入**设成酒馆后，打开 App 会直接进酒馆。

## 导入

<!-- nav: tavernTitle,tavernImport -->
`酒馆 › 导入`

**从文件导入**会自己认文件类型：角色卡（PNG、JSON、CHARX）、世界书、预设、正则、快速回复和 SillyTavern 的聊天记录。**从链接导入**粘贴角色卡站点的角色页地址或卡文件直链。一次选多个文件时会逐个提示结果；不是角色卡的文件会打开导入报告，列出导入时注意到的问题。

导入聊天记录要 SillyTavern 的 .jsonl 文件，可以一次选几个。导入 ST 主题也在**酒馆设置**的**显示**里。

## 书架、对话和角色页

**书架**顶部是最近聊过的对话，点**继续**接着上次；下面是角色网格，角色多时能搜索、按标签筛选、切换排序。

**对话**一栏列出全部聊天，最新的在上；顶部有**新建群聊**，书架上至少有两个角色时才可点。长按一条聊天可以删除。

点角色卡进角色页，分三个页签：**对话**里左右滑选**开场白**，点**开始**或**继续上次**；**设定**里是卡面与角色设定；**配置**里是它的世界书、Live2D 形象和导入报告。**编辑角色**只改能改的字段，卡里改不了的内容保存时原样保留，已有对话也不会变。

## 资源库

<!-- nav: tavernTitle,tavernSectionLibrary,tavernLorebooks -->
`酒馆 › 资源库 › 世界书`

**资源库**里是**世界书**、**预设**、**正则**、**默认人设**和**快速回复**。世界书、预设、正则都能从文件导入，也能编辑、做命中测试（世界书看哪些条目命中，正则看替换前后）。世界书设为全局后对所有对话生效，卡自带的世界书跟着卡走。**默认人设**是你在对话里扮演的人，长按可以设默认或删除。

## 开始一段对话

对话页上面是故事（舞台与消息），下面是输入条。发送键长按可以选**以旁白身份发**或**只发，不回复**；输入条旁的**帮我写**让模型替你写这一句，**接着写**让最后一条继续往下。输入条上方还有**快速回复**和**掷骰**：选好骰子，结果会放进输入框，确认后再发送。

## 换回答、分支和消息操作

任何一条角色回复都能左右滑切换**上一个回答**和**下一个回答**；最后一条向左滑到头等于**重新生成**。长按消息可以**复制**、**编辑**、**从这里分叉**、**重新生成**、**接着写**、**加书签**、**对模型隐藏**、**只删这一条**或**删除这条及以后**、**看看发了什么**。滑到别的备选时，顶部会提示**切到了另一条分支**，可以撤销。

**分支**页把整段对话的岔路画出来：缩进的行是从上一行末尾岔出的另一条路；点一行可以切过去或给它起名，没在走的那条也能删掉。

## 舞台

<!-- nav: tavernTitle,tavernStage -->
`酒馆 › 舞台`

对话页右上角的**舞台**键打开侧栏，分**本局**、**状态**、**导演**、**本回合**四栏：

- **本局**：这段对话正在用的模型、思考、人设、预设、世界书、排版和背景图；还有**书签**、**分支**、**在对话里搜索**、**导出聊天记录**和**导出成故事书**（电子书（EPUB）、纯文本（TXT）或**长图**）。
- **状态**：卡定义的状态，到当前这条消息为止。这回合变了的标着「+5」这样的记号；点一项能看全部或直接改，改动记在这条消息上，换回答、切分支会跟着回退。没定义状态的老卡会在这里列出它的变量。
- **导演**：打开**自动导演**后，它每隔几回合在后台读一遍剧情、记下**导演笔记**（默认藏着怕剧透），再给你几条建议回复；也能手动**让导演想一想**。**后台记录**里能看到每次状态改动和导演运行，最新的在上，最多 100 条。
- **本回合**：这一回合实际发出去的内容，能看完整的检视。

## 群聊

**新建群聊**时在**谁在里面**里选角色：按点选的顺序排，第一个是主持，故事共用的状态、导演和秘密记在它的卡上；主持可以不在发言名单里。群里可以看到谁在说，也可以**让大家接着说**；发言名单和顺序在**群聊设置**里改。

## 排版和酒馆设置

每段对话可以在**舞台**的**本局**里单独换排版，全局在**酒馆设置**里。酒馆设置按用途分组：

<!-- nav: tavernTitle,tavernSectionMe,tavernSettings -->
`酒馆 › 我的 › 酒馆设置`

- **模型与连接**：主模型选**Flash**或**V4 Pro**，开关**思考**，以及**DeepSeek API Key**（和对话共用设置里的 Key；没填时页面会提示去填写）。
- **生成**：默认预设的**回复上限**和**温度**；自带预设的对话以它自己的为准。
- **显示**：**排版**（**气泡**、**小说**、**视觉小说**）、**正文字号**、**配色**、是否**用卡自带的样式**、**导入 ST 主题**，以及消息里 HTML 面板和整页画布的开关。
- **安全**：**网页里不运行卡的脚本**、**网页不联网**，默认都关闭。
- **数据**：**备份整个酒馆**、**从备份恢复**、**用量统计**、**存储占用**。
- **你**：**默认人设**和**快速回复**。

酒馆首页的**我的**一栏里还有**启动时进入**，决定打开 App 时是否直接进酒馆。

## 备份和数据

角色卡、对话、世界书、预设、人设、设置和 Live2D 形象都只存在这台手机上。**酒馆设置**的**数据**里可以**备份整个酒馆**（打成一个 zip）和**从备份恢复**；**存储占用**按角色、对话、预设等分项统计。换手机、重置或卸载前先备份。**用量统计**里能看每段对话用了多少 token，包括缓存命中。

## 注意

- 酒馆直接连 DeepSeek，不经过本机引擎或远程主机；Key 在设置里填一次，酒馆和对话共用。
- 酒馆不审查卡和模型的内容；卡里写的 HTML 和脚本会在消息里运行。不想让它们跑，在**安全**里打开**网页里不运行卡的脚本**和**网页不联网**。
- 删除角色会连它的对话一起删掉，删除前会确认；这一步不能撤销。
- 长内容、很多对话会让每回合更贵：上下文越长，角色记得越多，花的 token 也越多。
