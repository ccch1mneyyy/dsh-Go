# 宠物

选一只宠物陪你对话：一轮完成、出错，或等你确认、回答时，它会冒个气泡提醒你。

## 选择宠物

<!-- nav: commonSettings,botsPets -->
`设置 › 宠物` · [打开](dshgo://open/pets)

在设置首页「外观」分组里点**宠物**，或在对话里长按宠物选**宠物设置**。先选一只宠物，下面的设置才会出现。

- 选 **Deepy 小鲸鱼**、**鲸娘**，或**不显示**。
- **大小**：**小**、**标准**、**大**，默认标准。
- **安静模式**：只做动作，不冒气泡。

鸿蒙版的宠物只在 App 里，没有 App 外显示，也没有悬浮宠物的「问一句」和气泡确认。

## 在对话里

- 宠物站在输入框上方，左右拖动可以换位置。
- 点气泡跳到对应的对话，上滑关掉气泡。
- 长按宠物：**换宠物**、**藏起来 1 小时**、**宠物设置**。藏起来期间，宠物页会出现**立即显示**。

## 伙伴小屋

伙伴小屋是一个单独的整页，里面住着一个会动的 Live2D 角色。它和上面的状态宠物是两回事：宠物替你盯着 agent，小屋是陪你待一会儿的地方。

打开「切换主机」面板，点**伙伴小屋**进入。第一次进来要导入素材包（zip）。角色素材不在 App 里，只存在这台手机上；在小屋右上角的菜单里可以移除。

鸿蒙版的她只在这一页里：不能待在悬浮窗里，也没有桌面小组件。

能做的事：

- 摸摸她：在头上来回滑动是摸头，点脸、身体、尾巴各有反应，连戳三下她会晕。这些都不调用模型，不花 token。
- 晃晃手机：把手机歪向一边，她会跟着水漂过去、身子一歪，再慢慢稳住；用力摇几下，她会被晃晕，冒一串泡泡。手机开了「减弱动态效果」时没有这些，没有运动传感器的手机上摇晃也没有反应。
- 和她说话：在下面的输入条打字或用语音。在右上角菜单的**对话方式**里选怎么聊：
  - **轻量**：只聊天。手机用你在设置里填的 DeepSeek API Key 直接连模型，不用启动引擎，也不用连主机。聊天记录只存在这台手机上，**重新认识**会把它删掉。用 DeepSeek 账号登录、没有填 Key 时用不了。
  - **完整**：用当前主机上的 DSH，是单独的一段对话，不进对话列表。菜单里的**查看聊天记录**可以打开它，**重新认识**开始一段新对话，旧记录留在主机上。她能用这台主机的工具；要动手的事会先请你确认。
  - 没选过的话，连着主机时用完整，没连时用轻量。
- 缩放：双指缩放和移动。
- 她的小角落：左下的贝壳盘里有点心，右边飘着泡泡球，身后是海草软垫。点贝壳喂她吃点心，点泡泡陪她玩，点软垫让她靠着歇一会儿。她在做什么，名字下面会写着。
- 喂她、抱她：点心可以从贝壳盘里拖出来，拖到她嘴边松手她就吃掉。手指在她身上按住不动是抱她。倾斜手机时，水里的礁石会跟着轻轻挪动。
- 她的声音：鸿蒙版还不能让她出声，菜单里的**她的声音**在这台手机上不起作用，手机自带的声音和外接语音服务都一样。
- 她的设定：在菜单的**她的设定**里改她的名字、她怎么叫你，以及她的人设：她是谁、什么性格、怎么说话，整段都能改，改坏了点**恢复默认**。默认人设里带着几条边界，不想要可以删掉；只有表情动作的标记格式由 App 自动加上。
- 越来越熟：常来看她、摸她，她会慢慢跟你更熟，菜单里的**你们的关系**能看到现在到哪一步了。熟了以后她会更常哼歌，被摸头时话也更亲。
- 别的对话：小屋开着时，你别的对话跑完、出错或者在等你批准，她会告诉你，点「去看看」直接过去。
- 她的邀请：你安静陪着她一会儿，她偶尔会在输入条上方问要不要一起在软垫上歇一会儿。点**好呀**她就靠过去；点**等会儿**或者不理它都行，过一阵她才会再问。不出声。她多久开一次口，在右上角菜单的**她多主动**里选：默认**偶尔**（一天最多两次，至少隔 6 小时），想让她多说点选**常常**或**话多**，不想被打扰选**安静**。提起别的对话也算在这个次数里。

她会记着你常来、常摸她的头，慢慢跟你更熟；你几天不来，她不会生气。想让她记住的事，可以在菜单的**她记得的事**里写下来，随时能改能删。完整模式下存在当前主机上，轻量模式下存在这台手机上。她现在还不会自己想起这些，也不会开口发声，只显示文字，也碰不到你的文件和手机。

如果这台主机的引擎比较旧，她会用默认预设运行，这时可能请求使用工具。页面上出现「有件事要你确认」时点开，到普通对话里处理。

## 创意工坊

创意工坊里是大家做的像素宠物和伙伴，挑喜欢的装到这台手机上，也可以把自己做的交上去。入口有两处：宠物设置页里的**创意工坊**一行，和伙伴小屋右上角菜单里的**创意工坊**。没有这一行，说明这个版本还没有接上工坊。

页面分三栏：

- **发现**：看、搜、按**像素宠物**或**伙伴**筛。点一项看介绍、作者、许可和大小，点**获取**下载安装。装宠物会多出一只可选的宠物，装伙伴会换成小屋里的角色；要覆盖本机已有的东西时会先问你。浏览和安装不用登录。
- **已安装**：从工坊装到这台手机上的东西。有新版本、被作者或审核撤回，这里会标出来；点开可以更新或卸载。没有网络时这一栏照样能看。
- **我的投稿**：你交上去的作品和它们的审核状态。要先登录论坛账号。

投稿：在**我的投稿**里点**投稿**，选一只自己导入的宠物或现在的伙伴，填名称、作者、许可和来源链接，看一眼打好的包，勾上**我确认自己有权分享这份内容**再交。宠物默认带一张预览图，用的是待机动画的第一帧，不想要可以关掉；伙伴可以选一张 PNG 当封面（每边不超过 512 像素、不超过 2 MB），不选就显示名字的第一个字。交上去先由审核员看，通过了大家才能在**发现**里看到；没通过会写明原因，改了可以再交。不想公开了，点开那条投稿选**撤回投稿**。

手机上记着的那份没交完的投稿读不出来了、或者一直清不掉时，那一步会多一个**放下这条记录**。它只删这台手机上的记录（如果这台手机上的投稿记录整体读不出来，会连其他账号的未完成记录一起清掉，确认框里会写明），不会让工坊取消什么：工坊要是已经收到，投稿还在**我的投稿**里；要是没收到，就得重新投。

第一次投稿、看自己的投稿或举报时，App 会先请你确认一件事：工坊靠论坛账号认人，办法是把你的论坛登录凭据发给工坊服务，由它去问论坛你是谁。确认页上写着这两个地址，你点了**同意并继续**才会发。不同意也能照常浏览和安装。

看到有问题的作品（侵权、内容不合适），在它的介绍里点**举报**并写明原因。举报交给审核员处理，作品不会因为举报自动下架。
