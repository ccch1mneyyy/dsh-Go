# 本机引擎与远程主机

DSH 可以直接运行在这台手机上（本机引擎），也可以运行在你的电脑或服务器上，由手机远程连接。对话、工作区和插件都属于各自的主机。

## 本机还是远程

第一次打开 App 时选择 DSH 在哪里运行：

- **本机**：在手机上安装运行环境，全程在本机完成。选项里会写明需要的存储空间和内存。
- **远程主机**：连接电脑或服务器上的 DSH，不在手机上安装。手机内存或存储不够时会推荐这一项。

之后随时可以补装本机环境：在引擎页点**安装运行环境**，或在切换主机时点**本机**。安装时请留在这个页面，装好后自动启动。

## 本机引擎

<!-- nav: commonSettings,hubSettingsEngine -->
`设置 › 本机引擎` · [打开](dshgo://open/engine)

- **启动**、**停止**、**重启**：停止前会确认；停止和重启都会中断进行中的对话。
- 启动失败时，页面显示失败原因和对应的修复按钮，如重试、**进入安全模式**、**恢复配置**、查看日志。
- **打开 App 时自动启动**：默认开启。只要装了本机环境，即使在用远程主机，打开 App 时也会启动本机引擎；不需要时关闭。
- **以安全模式启动**：手动进入安全模式，用随包的默认配置启动，不加载你装的插件。对话都在，原来的配置不会改动，但全局补丁和 `.env` 仍可能影响启动。修好后点**恢复正常模式**。这次打开 App 已经启动过引擎时，进入和退出都要重新打开 App，确认框会写明。
- 不会自动进入安全模式。连续几次没有正常退出时，引擎不会自己启动，失败卡片上可以点**恢复配置**、**进入安全模式**或**重试**。
- **日志**：引擎的实时输出。
- **后台运行**、**诊断**：见 [常见问题](11-faq.md)。

## Linux 环境

<!-- nav: commonSettings,linuxTitle -->
`设置 › Linux 环境`

在手机里运行 gh、Python 这类命令行工具。这一行只在鸿蒙版有，在设置首页「能力」分组里；要本机引擎在运行才能开。

- 打开**开启 Linux**。第一次会下载约 3.5 MB 的基础系统并安装，大约一两分钟，开关下面显示进行到哪一步：下载基础系统、准备磁盘、启动、安装工具。之后再开几秒就好。
- 开关会记住：开着的话，以后每次本机引擎启动都会自动接着打开 Linux。
- 开着时 App 大约多占 100 MB 以上内存；关掉开关后，要等 App 完全退出才会还给系统。
- 页面提示需要完全退出并重新打开 App 时（比如准备过程中关掉了开关），重新打开 App 后才能再开启。

开着时，AI 在本机引擎的对话里运行的 `gh`、`python3`、`python`、`pip`、`pip3` 会交给这个 Linux 执行，插件起的 Python 进程也一样；其他程序用 `linux <命令>` 运行，例如 `linux sh -c '…'`。`bash`、`git`、`rg`、`node` 仍在 App 自带的命令环境里运行。关着时，这些命令会报 Linux 环境未开启，不会自动安装。

Linux 里的命令看到的是这个对话的工作区，路径不变；对话权限是**仅可查看**时，工作区在 Linux 里也只能读。Linux 一次只跑一条命令；`pip` 启动较慢，可能要等几十秒。远程主机上的对话不用这个 Linux。

**网络代理**只作用于 Linux 里的命令，在**方式**里选：

- **跟随 App**（默认）：本机引擎用了代理就跟着用，没有就直连。
- **不用代理**：直连。
- **手动**：填 **HTTP 代理**、**HTTPS 代理**（不填时**同 HTTP**）和**不走代理的地址**（即 NO_PROXY，逗号分隔，例如 `example.com,10.0.0.0/8`）。代理地址以 `http://` 或 `https://` 开头，例如 `http://127.0.0.1:7890`；`127.0.0.1` 指的是这台手机，不是电脑，手机上的代理 App 请用 `http://`。两个代理都清空时回到**不用代理**。

gitee、华为云等国内源始终直连。代理只保存在这台手机上，改动对之后的命令生效。

重置或卸载运行环境不会删除 Linux 里装的东西，卸载 App 才会。开不了时见 [常见问题](11-faq.md)。

## 重置运行环境

<!-- nav: commonSettings,hubSettingsEngine,phoneEngineReset -->
`设置 › 本机引擎 › 重置运行环境`

删除本机数据后重新安装运行环境，用于修复无法启动的环境。确认框里可选：

- **保留界面配置和技能**：默认勾选。
- **保留已装插件和设置**：默认不勾选。

按默认确认，会删除对话、工作区、插件和设置，自定义模型渠道也在其中；家目录里没有保留的内容也会一起删除，包括工作区里的文件、`AGENTS.md`，以及插件自己存的数据（比如记忆）。主机列表、App 设置和已保存的密钥不受影响。确认框会写明这次删除的范围，点**删除并重置**后 App 会重新打开，在打开时完成重置。还差重新打开时，引擎页会提示，点**重新打开**即可；在这之前本机引擎不会启动。重置无法撤销，需要的对话先用 `/export` 或「全部功能」里的**导出对话日志**导出。

## 卸载运行环境

<!-- nav: commonSettings,hubSettingsEngine,localEnvUninstall -->
`设置 › 本机引擎 › 卸载运行环境`

删除已解压的运行环境和本机数据。本机的对话、工作区、插件、设置、界面配置和技能都会删除，App 会重新打开，不会自动重装。安装包里自带的那份运行环境还在，只有卸载 App 才会释放。之后想再用本机引擎，在同一页点**安装运行环境**。只是暂时不用时，停止引擎，并关闭**打开 App 时自动启动**。

## 切换主机

打开对话列表，点底部的当前主机名，打开**切换主机**，选择**本机**或一台远程主机。还没有远程主机时点**连接电脑或服务器**，已有时点**管理远程主机**。

点主机名左边的图标直接查看详情：远程主机显示主机名、连接状态和当前网络路径，支持时可手动测量延迟；本机打开**本机引擎**。主机名和下拉箭头仍用于切换主机。

## 添加 SSH 主机

那台主机需要开着 SSH，并装好 DSH（`npm i -g @deepseek-ai/dsh`）。

1. 在远程主机页点**添加 SSH 主机**。
2. 填写**主机**、**用户名**，**端口**默认 22。名称可以留空。
3. 选择**密码**或**私钥**登录。私钥可以**从文件导入**，有口令时填**私钥密码（可选）**。密码和私钥只保存在这台手机上。
4. **实例管理**默认**托管启动**：**启动命令**默认 `dsh web`；用 nvm 安装的 DSH 可以填完整路径。已有自己管理的实例时选**只连接**，填写**远端 DSH 端口**和该实例启动链接中的 **DSH 登录令牌**。**工作目录（可选）**是新对话的默认目录；只连接模式请用绝对路径。
5. 点**测试连接**。首次连接会弹出**信任这台主机？**：在那台主机上核对指纹，一致再点**信任并连接**。
6. 点**保存**，再在主机列表里选中它。

托管模式的测试连接会启动或复用远端 DSH，测试结束后它继续运行。**只连接**只建立 SSH 隧道到远端 `127.0.0.1` 的指定端口，不自动查找实例，不执行启动、停止或重启，不读写托管状态文件；请先在远端启动实例并保持运行。连接失败时检查端口与令牌，App 不会用重启修复它。令牌和密码、私钥一样，只保存在这台手机上。

托管模式发现仍活着但启动命令不同、日志丢失的实例时，会明确停止连接而不是自动杀掉它；登录令牌被拒绝、复用端口拒连也不会授权重启。先检查配置或改用**只连接**；确实要替换 App 记录的实例时，在编辑主机的 DSH 区选择**重启托管 DSH**，确认后才停止并重启。此操作可能中断其他客户端和进行中的对话，普通**测试连接**不会执行它。已确认死亡的托管进程仍可自动补启。

**SSH 压缩**默认开启，协商认证后压缩；服务器不支持时保持未压缩传输。可在主机编辑页关闭，保存后重新建立 SSH 连接生效。

修改或删除：点主机右侧的**编辑**按钮，进入**编辑主机**，底部是**删除这台主机**。删除只移除手机上保存的设置、密码、私钥和登录令牌，远端的 DSH 和对话不受影响。

## DSH Remote

无需配置网络，连接端到端加密，适合不在同一网络的电脑。

1. 在那台主机的 DSH 里装好远程插件并登录。
2. 在远程主机页选择你在那台主机上使用的登录方式，例如「使用 GitHub 登录」，再用同一账号登录。如果页面没有列出登录方式，只显示**在浏览器中登录**，点它继续。
3. 在列表里选中在线的主机。首次连接时核对身份指纹，与主机上远程插件显示的一致再点**信任并连接**。

服务器支持时，远程主机页会出现**扫码配对电脑**：先在 App 登录 DeepSeek，点**扫码**打开系统扫码页，扫电脑 Remote 插件显示的配对二维码，核对电脑指纹后按提示输入验证码。扫码页由系统提供，相机归它使用，DSH Go 不申请相机权限；二维码在截图里时，在扫码页里从相册选图即可。也可以复制配对链接，点**粘贴配对链接**。系统扫码打不开时，会提示改用粘贴配对链接。

当前版本走 Relay 中继，全程端到端加密，不走局域网、P2P 或 TURN。点击连接卡或主机旁的网络标签，查看实际路径、连接耗时和可测的往返延迟；未测量的项目不会显示为零。

<!-- nav: commonSettings,commonRemoteHost,remoteCompactHistory -->
`设置 › 远程主机 › 精简历史`

**精简历史**默认关闭。开启后，支持的 DSH Remote 主机会把历史工具参数和输出转为摘要，减少历史传输量；正文、实时回复和审批不变，也不会修改主机原始记录。切换到其他主机（或本机）后再连回来，或重启 App 后生效；当前连接及其自动重连保留原模式，避免历史缓存混用。关闭后同样需要重新选择主机，再打开对话获取完整历史。旧主机没有该能力时仍传输完整历史，SSH 不受此设置影响。

DSH Remote 一次只连一台主机，切换会断开上一台。经 DSH Remote 连接时：只能发送图片；App 内打不开网页版；插件只能开关；DS Bot 和导出对话日志不可用。
