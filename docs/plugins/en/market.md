# Publishing and listing

A plugin goes through three layers: an npm package → a market index → installable in the app. They are independent; confirm each one.

## 1. Publish the npm package

The package is the base. Build and publish steps are in [From zero to market](from-zero.md) §6. Key points:

- You own the package name; `cordis.patch.yml`'s `name` must match it exactly; quote scoped names in YAML.
- Set `engines.dsh` and peers to a version range you actually tested.
- `repository` points at the real public repo; add `dsh-plugin` and `dsh-bundle` to `keywords`.
- Choose an OSI-approved licence and ship a LICENSE; keep metadata truthful.
- Publish with `npm publish --access public --ignore-scripts` only if the plugin has no build scripts such as `prepare` or `prepublishOnly`; if it depends on them, finish the build and tests first as in [From zero to market](from-zero.md) §6. Then check with `npm view <name> name version repository dist.integrity --json`.

## 2. Enter the discovery index (dshfind)

By default the app reads dshfind's format-1 index. Add the `dsh-plugin` topic to the public repo and check npm's `repository` back-link; the discovery task picks it up on a refresh (no fixed deadline promised).

Listing conditions (2026-10): recognised as a plugin, no risk flag, ship a bundle, published to npm, back-link matches, valid name and version; `@deepseek-ai/*` is not listed. Version compatibility is checked by the installer; risk flags are set by the market, not by authors.

## 3. List in the official market (dsh-go-market)

The app's plugin market has three entries: **official**, **adapted for DSH Go**, and **all**. For packages in the official catalogue it uses a pinned, reviewed version, and shows risk flags, adaptation notes, the minimum app version, screenshots and bilingual descriptions.

To submit:

1. Go to [dsh-go-market](https://github.com/ccch1mneyyy/dsh-go-market), follow its "submit a plugin" guide, add one `plugins/*.json` entry and open a PR.
2. Author fields only (package name, exact version, title, summary, category, screenshots, homepage); tier, risk and integrity are generated by that repository — authors can't set them.
3. Review and auto-merge follow that repository's rules. **Those rules win**; this page only describes how the app consumes the data.

Details:

- Each entry pins an **exact version** that matches npm.
- Pick a category from the fixed set the market declares; screenshots over HTTPS only, at most four.
- The licence must be OSI-approved; package size has a cap (around 50 MiB; see that repository's rules).
- **Official status comes only from that repository's policy.json** — authors cannot declare it.
- A risk flag describes what the package can do; it is **not a security guarantee**. Medium/high-risk installs list the reasons and ask before continuing.

## 4. Four independent states

A web page, an npm release, a market index entry and an installable app are four separate things:

| State | How to confirm |
|---|---|
| Published on npm | `npm view … --json` |
| In the dshfind index | query dshfind's format-1 index `https://api.dshfind.com/market/dsh-index.json` by exact name (see the from-zero example); it feeds the **all** section |
| In the official market index | query the official market's format-1 index `https://go.dshtui.com/market/index.json` by exact name; it feeds the **official** and **adapted for DSH Go** sections |
| Visible in the app | search the app, check version, source and section filter |
| Installs and runs | install on the target host and make one real tool call |

## Troubleshooting

| Symptom | Check first |
|---|---|
| On the site but not in the app | index result, current section filter, exact version, npm back-link |
| Missing from official, only under all | whether the submission merged, and whether its version matches npm |
| A risk confirmation appears | the flag comes from an automatic scan of the package contents (install scripts, native binaries, subprocesses, file writes, network use), not only declared capabilities; look up the exact file paths for your package in `audit.json` of [dsh-go-market](https://github.com/ccch1mneyyy/dsh-go-market); install can continue after confirming |
| An installed version was delisted | the details page warns; publish a fixed version and update the entry |
