# 原生批准文本的可见表示

本增量对应 ADDENDUM-08 §3.4。执行计划的参数字典、text 和两条后端的输入值保持原字节；确认显示单独生成，不再把原始 text 直接拼进可信说明。完整输入的可见表示包在 ASCII 双引号内，**不截断输入文本**。目标标签及其它标识仍有原来的80个Unicode标量显示上限，超出显示省略号；执行标识本身不因此改写。

## 拒绝与显示

模型参数继续拒绝既有C0/C1、双向控制及行/段分隔符；新增拒绝所有Cf格式字符及题面额外的U+2800、U+3164、U+FFF9–FFFB、U+E0000–E007F。固定Unicode17/18的Cf集合为170项，和额外范围合并后203项；另叠加系统运行时generalCategory=format，不依赖旧系统是否已经认识新格式字符。包含ZWJ的组合emoji、使用ZWNJ的正常拼写也会保守拒绝；不能将它们删除后继续输入。

OCR目标标签可能含被拒绝的字符，因此显示层把同集合和Default_Ignorable_Code_Point转成可见编码。非Cf的默认可忽略字符（例如FE0F）仍可存在于合法执行文本，但在确认文本中显示为转义。连续Unicode空白在显示里折成一个普通空格，包括首尾空白；执行时仍保留原文和原数量。原控制字符先转义，不能借OCR中的换行插入新的说明段。

双引号、单引号、反引号及反斜线使用反斜线加原字符的紧凑显示；其它需要转义的BMP标量用\uXXXX，非BMP用\u{XXXXX}或\u{XXXXXX}。原文中的字面反斜线自身也转义，所以实际不可见字符与字面文本\u200B具有不同显示。弹窗明确说明这是显示表示，实际输入保留原文。

## 引号数据与版本选择

引号显示集合取固定Unicode17和18数据的并集，并继续接纳运行时isQuotationMark的新识别结果。来源包括Quotation_Mark属性、confusables中目标完全由ASCII双引号/单引号/反引号构成的记录，以及命名的引号装饰符；PRIME名称集合在这些集合内。17集合86项，18集合87项，保留17旧覆盖再加入18新增4项后为90项。18文件不再列出的U+0374/U+1FEF/U+1FFD仍保持转义；记录移除并不证明字形风险消失。

该策略也会把少数正常字母（如希伯来字母Yod）显示成编码，但不改执行值。这是有限的显示判据，**不证明所有字体、组合附加符、双向文本或视觉混淆均已解决**。现有OTP判据仍是有限启发式：例如数字间夹非Cf的FE0F仍可能不被它分类为短数字码。这里仅明确显示该标量，不冒称OTP检测已完备，也不扩写执行文本归一化规则。

## 字节上界与执行证据

有效模型文本B≤4096 UTF-8字节；已拒绝单字节控制字符。ASCII紧凑转义≤2倍，非ASCII BMP编码6字节且原占≥2字节，非BMP编码≤10字节且原占4字节，空白折叠不增加长度。因此完整输入显示≤3B+2≤12290字节。OCR目标允许控制字符，另按80标量×10字节+两引号+省略号3字节计，通用上界805；screen按96原字节的保守界为293。

绑定本批固定源：type固定文案876、id至多3、上述text/screen/target界，再加Runner路线说明126、TaskConsent目标步骤156和剪贴板步骤258，整个提示的保守上界为14807字节，比16384少1577。这里是源级代数推导，不是Swift执行；TaskConsent的既有guard在追加其自身文案之前，未来文案变化必须重新计算。新增最大长度测试调用真实Operation格式器，完整保留2048个二字节引号字符的可见编码，并为固定附加说明留出1024字节。

原25个测试方法及原辅助代码保持，新加11个方法：题面不可见范围、其它Cf、所有字符串参数、OCR可见编码、多种引号、原始反斜线歧义、混合空白、首尾/全空白、非Cf默认可忽略字符、最大显示预算和实际测试宿主许可资源。**36 authored / 0 executed，Apple UNRUN。** 无Swift/Xcode/设备/字体渲染结果。固定表逐集合对照官方数据、私有index及普通目录应用是独立证据，不能替代这些运行验收。
