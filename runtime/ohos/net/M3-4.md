# M3-4：默认代理需显式启用，回环目标直连

固定验证 Node **24.22.1**。本项后继差分依赖已审 M3-3 主包 `4b151149dff8c1bef38b74fd4cf344fad01be2a36fba48361cede5b63af4a751`；另提供从干净 **c0949d6** 应用的累积补丁。两条路线最终源码与 pins 必须逐字相同，不能同时叠加。O4 附属迁移不在本累积包内，仍按各自精确版本应用。

## 改动与理由

`installFetch()` 只有在 `NODE_USE_ENV_PROXY === '1'` 时采纳环境代理。未设置、为 `0` 或其他值时，默认连接池显式使用空 `proxyEnv`。这对应追加3指定的默认行为；不会因其他程序留下 `HTTP_PROXY` 就改变本入口的请求路由。

工厂 `createHttpDispatcher({ proxyEnv })` 和单次 fetch 的显式 `dispatcher` 仍保留调用方策略。DSH 既有代理服务也继续把解析过的策略明确传给工厂；没有因默认 opt-in 修复而抹掉用户明确配置的代理或 DNS 地址固定。

本工厂从 URL 已规范化的 hostname 判定回环：IPv4 `127.0.0.0/8`、IPv6 `::1`、IPv4 映射 IPv6，以及 `localhost` / `.localhost` 后缀。保留 DSH 对 `0.0.0.0` 和 `::` 的本地地址直连规则。数字/缩写 IPv4 先由原生 URL 规范化，再由公开 `net.BlockList` 检查地址范围。`.localhost` 和尾点/大小写处理沿用已有 DSH policy 的边界；`localhost.example.invalid` 不属于该后缀。

回环请求使用本 dispatcher 内独立的直连 Agent，传 `proxyEnv: {}`，即使工厂显式配置了代理也不向代理发出这个请求。直连池继续使用调用方的 `lookup`、`ca`、`autoSelectFamily`。不会为普通待代理域名先做本机 DNS 查询，也不把一个公有域名仅因 DNS 返回地址不同而改成另一种代理策略。

普通 HTTP/HTTPS Agent 仍在工厂建立时读取明确配置，避免调用方事后修改 `proxyEnv` 改变原本已经建立的策略；回环池按需建立。`close()` 和 `destroy()` 管理全部池。显式传入的外部第三方 dispatcher 仍由其调用方负责，本模块不改写它的内部路由。

## 真实测量

所有目标与代理都在本机启动，非回环目标取本机网卡地址，没有访问外部业务网络。服务器分别记录 origin、proxy、CONNECT 到达次数，不能只凭返回字符串判断是否绕过代理。

| 测量 | 结果 |
| --- | --- |
| 原始九条矩阵，含原生 Node 无 opt-in 正对照 | 修复后 9/9 PASS；修复前 2 PASS、7 FAIL |
| 新路由矩阵在冻结 M3-3 实现上 | 19 项，5 PASS、14 FAIL；日志保留 |
| 最终路由矩阵，marker-only JIT | 20/20 PASS，0 skip/TODO |
| 同一最终矩阵，完整 O0 + jitless | 20/20 PASS，0 skip/TODO |
| 网络核心，普通 Node / 完整 O0 | 每轮 36 PASS、5 TODO、0 SKIP |
| DSH Android 对照 / JIT 集成 / 完整 O0 集成 | 4/4、13/13、13/13 PASS，0 skip/TODO |

矩阵覆盖无 opt-in、`0`、`1`、NO_PROXY、大小写环境变量优先级、显式工厂代理，以及 `127.0.0.1`、`127.2.3.4`、`localhost`、`::1`、两种映射 IPv6 写法、`127.1`、整数 IPv4。另测 `.localhost` 的明确 lookup、相似但非 localhost 域名、HTTPS 直连及 CA 验证。

连接关闭断言在 Worker **仍存活** 时等待服务器的 socket close，并检查普通池和回环池都已释放；没有以随后终止 Worker 的自动清理冒充 `dispatcher.close()`。作者未冻结初稿曾把所有池改成懒创建，新增的配置捕获测试实测失败，随后恢复普通池原有创建时机；这条失败属于开发初稿，不归因于 c0949d6，日志另存。

原有五个 Fetch TODO 仍失败并保留。M3-5 的全局 dispatcher 恢复、closed policy 与 headers 问题由下一包处理。本项没有鸿蒙真机结果；同一 O0b 五工具回合由主验证树按实际装配输入另录。
